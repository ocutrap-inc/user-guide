# Trap Settings

<figure><img src="../../../.gitbook/assets/image (30).png" alt="" width="375"><figcaption></figcaption></figure>

Trap settings control how each trap detects, captures, and alerts — including your **capture distance**, **notification preferences**, and **camera behavior**. Open a trap and tap **Settings** to adjust them; tap **More Settings** for the full list.

## Name, Notes, and map location

Trap identity lives on the **trap detail** screen (top bar), not under Settings:

* **Name** — what the trap is called in your lists and alerts. Tap the name to edit (owner/manager).
* **Notes** — one free-form field for site detail (access directions, gate code, customer, etc.). Tap **Notes** in the top bar to edit. There is no separate “location note.”
* **Map location** — the site line under the name reflects the trap’s map fix (GPS or a location you set manually). Use **Set location** to place a pin or enter an address; that stamps a manual map position. It does not replace Notes.

Everyone you share the trap with can both read **and edit** name and notes — sharing has no view-only level, so every shared user is a manager. Leave out anything you would not want a shared user to see or change.
