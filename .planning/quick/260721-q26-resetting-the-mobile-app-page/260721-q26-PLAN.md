# Quick task q26 — Resetting the mobile app (iOS & Android)

**Date:** 2026-07-21
**Spec:** DOC-10
**exit-impact:** ops

## Problem

Support often asks customers to force-quit or reinstall the OcuTrap mobile app
(stuck UI, missing push notifications, stale session). The guide only mentions
reinstall in one FAQ bullet; there is no dedicated how-to for iOS and Android.

## Plan

1. Add `troubleshooting/resetting-the-mobile-app.md` — force quit, optional
   Android cache clear, delete + reinstall, post-reinstall sign-in and
   notification permissions. Clarify that account/traps/subscription stay in
   the cloud.
2. Nav: new bullet at end of `## Troubleshooting` in `SUMMARY.md`.
3. Cross-link from `using-the-mobile-app.md` and the push-notifications FAQ.
4. Mirror root ↔ `docs-site/content/` (byte-identical). Regenerate KB PDF if
   the local build is straightforward; otherwise leave to CI on merge to main.

## Out of scope

- Web app "hard refresh" (browser) — this page is mobile only.
- Account deletion or password reset (already documented elsewhere).
