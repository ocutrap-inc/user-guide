# Quick 28 — GitHub Enterprise runner cutover

**Date:** 2026-08-03  
**Spec:** PLAT-GH-09 / SW-808  
**exit-impact:** ops

## Problem

The knowledge-base PDF workflow still purchases Linux capacity through Blacksmith even though the organization now has GitHub Enterprise standard-runner minutes. Keeping the third-party label creates avoidable recurring cost and leaves the workflow coupled to a provider the organization is exiting.

## Plan

1. Preserve the existing PDF verification and synchronization behavior, triggers, permissions, commands, and check names.
2. Replace only the two Blacksmith Linux runner labels with the standard GitHub-hosted `ubuntu-latest` label.
3. Validate the workflow syntax and local PDF verification, then confirm the PR workflow is green before merge.
