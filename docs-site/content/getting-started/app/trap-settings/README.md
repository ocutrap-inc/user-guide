# Trap Settings

<figure><img src="../../../.gitbook/assets/image (30).png" alt="" width="375"><figcaption></figcaption></figure>

Trap settings control how each trap detects, captures, and alerts — including **capture distance**, **camera behavior**, **alerts**, and **battery** handling. Open a trap and select the **Settings** tab; every setting is on that one screen.
