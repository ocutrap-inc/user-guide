# Quick task q30 — EDC default and advanced-setting warning

**Date:** 2026-08-10
**Spec:** DOC-20
**exit-impact:** ops

## Problem

The EDC calibration guide states that 50 ms is the default, but it does not
prominently tell customers to leave that value alone when the door already
finishes under the locking bar. Because both a too-short and a too-long value
can defeat the EDC recovery, the control needs to be labeled as an advanced
per-trap setting rather than a routine preference.

## Plan

1. Add a warning callout beside the EDC Backoff explanation: default 50 ms;
   leave it unchanged when the door consistently finishes under the bar.
2. State that this is an advanced setting and incorrect timing can prevent EDC
   recovery or leave the door effectively unlocked.
3. Repeat the caveat in the More Settings overview, settings reference, and
   hand-maintained Knowledge Base source.
4. Sync site mirrors, rebuild the site and PDF, visually inspect the warning,
   then publish through the normal PR and production deployment.

## Out of scope

- Changing the 50 ms product default.
- Changing the calibration procedure or firmware behavior.
